# 测试配置约定（长期有效）

> 建立日期：2026-11-05
> 适用范围：本仓库此后所有 benchmark / 抽测 / 单次验证

---

## 1. 一律关闭思考模式

**所有测试固定 `--reasoning off`，不再对"思考开"做对照跑。**

理由（来自 851 次五阶段实测）：

| 模型 | 思考关 PASS | 思考开 PASS | 结论 |
|---|---|---|---|
| LFM3 1.7B | 10/185 | 11/185 | 噪声级差异 |
| Qwen3.5 4B | 13/185 | 10/185 | 思考开更差 |

同时思考开把平均耗时推到 155–174 s、74–91% 的运行撞 180 s 墙钟，
并在输出预算上挤占答案空间（见 [PROBE-2026-11-04.md](PROBE-2026-11-04.md) 第 2 节）。
**收益为零、代价明确，因此今后不再开启。**

### 1.1 历史数据的处理

已完成的四个「思考开」阶段（phase2 / phase3 / phase3b 及部分 phase1 对照）**保留不删**，
作为历史对照记录；但**不作为未来实验的默认配置**，也不再重复跑思考开的组。

## 2. 其他固定参数（沿用）

| 项 | 值 |
|---|---|
| 上下文 | 主表 65536；低于 8K 不可用（`pi-ai` 固定预留 4096 tokens） |
| 墙钟 | 180 s / 次 |
| 输出上限 | `min(4096, ctx/2)` |
| 并发 | LFM3 三槽（`-np 3`）；Qwen 单槽（`-np 1`，双槽 OOM） |
| 搜索 | 五个 arm 均具备同源同范围搜索（见 [adapters/](../../adapters/)） |
| 搜索 API | DeepSeek 搜索插件全程禁用，`DEEPSEEK_API_KEY` 从被测进程剔除 |

---

## 3. 8K 的可用性

8K 在**单轮**问答下可用，但**多轮工具调用会触发 `BUDGET_INVALID`**
（prompt 增长后 `available = ctx - est - 4096` 掉到 256 以下）。
因此"每改一次跑 8K 单测"这件事**做不到**，改用 16K 做抽测。

---

## 4. 抽测规程（每次代码改动后）

1. 服务器切到：目标模型 / 16K / `--reasoning off` / 单槽；
2. 跑 2 个 arm（A 极简 + D slim 有搜索）各 1 次，任务 A1；
3. 记录 `STATUS / search_calls / official_hits / final`；
4. 只有出现 PASS 或 `official_hits` 非空，才算改动产生了**方向性**改善。
